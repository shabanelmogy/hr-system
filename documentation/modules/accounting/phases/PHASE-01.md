# Phase 01 — الأساس التقني والأمني

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 00

## الهدف

منصة آمنة وصالحة لبناء الدورات المالية على API وقاعدة بيانات وبيئتي الويب
والموبايل.

## التسليمات

- هيكل التطبيقات وAPI وقاعدة البيانات وmigrations وبيئات التطوير/الاختبار/
  الإنتاج وCI.
- في هذا المستودع تعيد Accounting استخدام الدخول والجلسات والمستخدمين
  والمستأجرين والشركات والفروع التي تملكها HR/طبقة المنصة عبر Contracts أو
  abstractions مستقرة؛ Accounting يملك فقط سياسات الصلاحيات المالية وتفويض
  العمليات الحساسة الخاصة به.
- سجل تدقيق، مرفقات محمية واحتفاظ ومنع فقد الأدلة، مهام خلفية وإشعارات موثوقة.
- مكونات النماذج والجداول والحوار والصلاحيات وحالات التحميل والخطأ بالعربية/
  الإنجليزية وRTL، ونسخ واستعادة ومراقبة أسرار وشركة تجربة معزولة.

## القبول

اختبارات API وقاعدة فعلية تثبت عزل شركتين ومستأجرين في البيانات والملفات والمهام؛
استعادة تجريبية ناجحة ومقاسة؛ وعدم إنشاء جداول أو خدمات أو واجهات دخول/مستخدمين/
شركات/فروع مكررة داخل Accounting. إخفاء زر الواجهة وحده ليس حماية.

## قائمة التحقق

- [ ] اكتمل **reuse inventory** وفق [فهرس القواعد](README.md).
- [ ] ثبت استهلاك قدرات الهوية/المستأجر/الشركة/الفرع القائمة دون نسخها، وثبتت
  سياسات Accounting المالية على الخادم.
- [ ] ثبت العزل والاستعادة ومراقبة الأخطاء على المنصتين.
