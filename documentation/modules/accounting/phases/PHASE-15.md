# Phase 15 — الأصول والإهلاك

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 11، 14

## الهدف

تقديم دورة أصل مالية كاملة متطابقة مع الأستاذ.

## التسليمات

مجموعات وبطاقات ومكونات، أصل تحت الإنشاء وغير قابل للإهلاك، اقتناء وافتتاحيات
وربط فاتورة ورسملة، تكلفة ومجمع وانخفاض، سياسات وعمر وقيمة تخريدية وجاهزية،
جداول بإصدارات ودفعات إهلاك وتحسين ونقل وتغير تقدير وتصرف جزئي/كلي وتصحيح.
تقسم إلى 15A السجل/الاقتناء، 15B الجداول/الدفعات، 15C التصرف/التغيرات/المطابقة.

## القبول

بطاقة شراء لا تعيد التكلفة؛ افتتاح لا يعيد أقساط الماضي؛ هوية القسط تمنع
التكرار عبر نسخ الجدول؛ سباق الإهلاك والتصرف محمي. مثال تحقق: تكلفة 120,000
وتخريدية 12,000 على 36 شهراً = 3,000 شهرياً، وبعد سنة قيمة دفترية 84,000.
