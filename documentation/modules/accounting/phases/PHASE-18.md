# Phase 18 — مصمم القوائم وحزمة التقارير

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 08، 13، 14، 15، 16، و17 عند الانطباق

## الهدف

إتاحة قوائم قابلة للتصميم والاعتماد ومتطابقة على الويب والموبايل.

## التسليمات

مصمم مستقل على المنصتين؛ بنود شجرية وروابط حسابات ومعادلات آمنة وأعمدة ومقارنات؛
قوالب وإصدارات ونشر وأرشفة؛ دخل ومركز مالي وتدفقات مباشرة/غير مباشرة وتغيرات
حقوق الملكية وإيضاحات وحزمة أدلة وتصدير. يقسم إلى 18A المحرر/النسخ، 18B القوائم/
التدفقات، 18C المقارنات/الأدلة/التصدير.

## القبول

منع دورات المعادلات وتداخل الربط وتكرار الإجمالي وتسريب البيانات، وعدم احتساب
نتيجة السنة مرتين؛ التقرير المعتمد يحفظ نسخة القالب والفلاتر والبيانات؛ الشاشة
والملف متطابقان؛ لا SQL أو كود حر.
