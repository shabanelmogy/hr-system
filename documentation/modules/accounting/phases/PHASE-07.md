# Phase 07 — الأستاذ المساعد والافتتاحيات

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 06

## الهدف

ربط تفاصيل الذمم بالأستاذ وإتاحة افتتاحيات قابلة للمطابقة دون تحميل مزدوج.

## التسليمات

مستحقات وشروط وأقساط، تخصيص جزئي/كامل وعكس مؤرخ، فروق عملة محققة، خصم وشطب
معتمدان، افتتاحيات حسابات وشركاء وأبعاد، أعمار تاريخية ومتابعة ديون.

## القبول

تطابق التفاصيل وحساب المراقبة؛ منع التخصيص الزائد أو المتزامن؛ الأعمار تعكس
الحالة في التاريخ؛ القسط لا يكرر الإيراد؛ فروق السداد عند التسوية؛ وافتتاحيات
الأصول والشيكات تؤجل لسجلاتها.
