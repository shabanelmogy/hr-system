# قالب متابعة المرحلة

انسخ هذا القالب لكل Phase عند بدء العمل. طبّق بوابة reuse inventory من
[فهرس المراحل](README.md) قبل أي تصميم أو كود.

| الحقل | القيمة |
| --- | --- |
| رقم المرحلة واسمها | يملأ عند البدء |
| الحالة | Planned / In progress / Blocked / Ready for review / Approved / N/A بقرار |
| مسؤول التنفيذ والمراجع | يحددان |
| الاعتماديات وأدلة اكتمالها | روابط التسليم المعتمدة |
| التقدير والبدء والنهاية المستهدفة | بعد تحليل الفريق |
| قرارات مفتوحة ومالك وموعد البوابة | يحددان قبل التنفيذ |
| نتيجة reuse inventory | reused / extended / rejected / new-local مع السبب |
| عقود البيانات وAPI والحالات والصلاحيات | روابط وثائق الإصدار |
| الويب والموبايل والعربية/الإنجليزية/RTL | تسليم واختبارات كل منصة |
| نتائج الاختبارات والمطابقة | النتائج الفعلية وحدودها |
| المخاطر والموانع | الإجراء والمالك |
| دليل الاعتماد | اسم المراجع والتاريخ والنسخة |

## قائمة تسليم كل مرحلة

- [ ] الاعتماديات والقرارات اللازمة مكتملة.
- [ ] حالات الاستخدام وانتقالات المستند وقواعد العمل موثقة.
- [ ] نموذج البيانات وعقود API والصلاحيات معتمدة.
- [ ] قواعد الحساب والتحقق على الخادم.
- [ ] الويب والموبايل والعربية/الإنجليزية وRTL حسب النطاق.
- [ ] اختبارات القواعد والعزل والتزامن والتكامل ذات الصلة ناجحة.
- [ ] سيناريو تجربة بأرقام متوقعة ومطابقة فعلية.
- [ ] مرفقات وتدقيق وتقارير وتصحيح متاحة حيث تنطبق.
- [ ] دليل التشغيل والقيود المعروفة محدث.
- [ ] المراجع اعتمد التسليم بالأدلة؛ الشاشة أو الملف وحده لا يثبت الإنجاز.
