# Phase 04 — الأبعاد والتوزيعات

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 02، Phase 03

## الهدف

توفير تحليل مالي مضبوط دون تضخيم القيم أو فقد غير المصنف.

## التسليمات

أبعاد معرفة بالمستخدم وقيم مسطحة/شجرية، إلزام مشروط بالحساب والمستند والفترة،
قواعد توزيع بإصدارات وأولوية، محرر نسب ومبالغ، توزيع مركب وتصحيح تحليلي مستقل
يحفظ الأصل.

## القبول

كل توزيع يطابق أساسه مع تقريب حتمي؛ غير المصنف لا يختفي؛ لا استنتاج لتقاطع
الأبعاد بضرب النسب (يحفظ تقاطع معتمد أو يعلن عدم توفره)؛ والفرع التحليلي لا
يتجاوز التفويض الحقيقي.
