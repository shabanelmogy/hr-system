# Phase 09 — محرك الضرائب وعقد البلد

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 03، 05، 06

## الهدف

تثبيت حساب الضرائب وعقد الدولة قبل بناء الفواتير.

## التسليمات

معاملات وقواعد مؤرخة، إعفاء واسترداد وخصم/حجز عند الانطباق، حسابات وأساليب
تقريب، عقد البنود والمقدمات والإشعارات، وحقول البلد اللازمة للتكامل اللاحق.

## القبول

حالات حساب متفق عليها مع المحاسب لكل بلد ونسخة معاملة محفوظة؛ غياب سياسة لازمة
يمنع المسار الخاضع؛ لا ادعاء جاهزية الإرسال الإلكتروني قبل Phase 14.

## قائمة التحقق

- [ ] اكتمل **reuse inventory** وفق [فهرس القواعد](README.md).
- [ ] اعتمد محرك الضرائب وعقد المستندات وسياسات كل بلد من المالك.
