# Phase 02 — التهيئة ودليل الحسابات

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 01

## الهدف

بناء الهيكل المحاسبي القابل للإصدار والتأسيس دون إفساد التاريخ.

## التسليمات

شجرة الحسابات وتصنيفاتها وطبيعتها وحسابات المراقبة ومستويات الأكواد والعملة
الأساسية والسنوات والفترات والأقفال، مع استيراد/تصدير ومعالج تأسيس بإصدارات
ومعاينة.

## القبول

منع الدورات وتكرار الأكواد والترحيل على الحساب التجميعي؛ هوية الحساب مستقلة عن
كوده؛ المستخدم يؤرشف ولا يحذف؛ التعديلات لا تفسد التاريخ؛ لا تداخل غير مسموح
للفترات؛ ومحرك Phase 06 يثبت القفل وقت الترحيل.

- [ ] اعتمد الدليل والفترات وحزمة التأسيس مع اختبارات العزل والصلاحيات.
