# Phase 06 — محرك القيود والاعتماد

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 03، 04، 05

## الهدف

إنشاء مصدر موحد للأثر المالي مع قيود متوازنة، immutable، قابلة للتدقيق
والتصحيح بأثر جديد.

## التسليمات

قيود يدوية وآلية، معاينة واعتماد وترحيل، تحقق الحساب والفترة والأبعاد والتوازن،
منع التكرار والتزامن، إلغاء المسودة وعكس وتصحيح المرحل، روابط المصدر والأثر،
تدقيق وفحوص الأثر المتوقع/المفقود. يقسم داخلياً إلى 06A العقود/الحالات/المحرك،
06B الموافقات/التصحيح، و06C الفحوص والإصلاح المؤهل بمعاينة واعتماد.

## القبول

لا تعديل أو حذف أو Unpost لمرحل؛ إعادة الطلب لا تكرر القيد؛ الأصل والعكس يظهران
بتاريخيهما؛ Backfill لا يخمن ولا يتجاوز القفل؛ الإشعار بعد نجاح المعاملة فقط؛
اختبارات فشل الدفعة والتزامن وإعادة المحاولة تثبت idempotency.
