# Phase 16 — الاستحقاقات والمؤجلات

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 11، 14

## الهدف

فصل الاعتراف المالي عن الدفع مع جداول قابلة للتصحيح.

## التسليمات

جداول مصروفات وإيرادات مؤجلة، استحقاق وعكس مجدول، إصدارات ومعاينة واعتماد
ودفعات، تعديل المستقبل والإنهاء وتصحيح الماضي وربط المصدر والأبعاد.

## القبول

الموزع والمتبقي يطابقان المصدر؛ الجدول لا يثبت دفعاً؛ إعادة التشغيل لا تكرر
القيد؛ الفترة المقفلة تمنع الترحيل ولا تنقل التاريخ خفية؛ وإلغاء المصدر يفحص
الاعترافات اللاحقة.
