# Phase 11 — الفواتير المالية

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 09، 10

## الهدف

تقديم دورة فاتورة مالية إلى سداد وتصحيح دون حركة مخزون.

## التسليمات

فواتير عملاء وموردين للخدمات والمصروفات والأصول، بنود مالية، مقدمات وأقساط،
إشعارات ومرتجعات جزئية/كلية، حد ائتمان، منع تكرار فاتورة المورد، طباعة ومرفقات
وروابط المستحق والسداد.

## القبول

إثبات الإيراد/المصروف/الأصل والذمة مرة واحدة؛ الإشعار لا يعني رد نقدية تلقائياً؛
لا حركات كمية أو COGS؛ ولا إطلاق مستند خاضع قبل متطلبات Phase 14.

## قائمة التحقق

- [ ] اكتمل **reuse inventory** وفق [فهرس القواعد](README.md).
- [ ] اختبرت الفاتورة والضريبة والسداد والتصحيح ومنع الازدواج على المنصتين.
