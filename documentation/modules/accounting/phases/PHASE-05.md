# Phase 05 — الدفاتر والعملات والترقيم

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 02

## الهدف

توحيد تعريف المستند ورقمه وسعره قبل اعتماد الأثر المالي.

## التسليمات

دفاتر بأنواع وحسابات وصلاحيات؛ سلاسل ترقيم مؤرخة وحجز آمن؛ عملات ودقة واتجاه
السعر ومصدره؛ أسعار يومية واستيراد وتجاوز بسبب ومعاينة أثر التعديل.

## القبول

طلبان متزامنان لا يأخذان نفس الرقم ولا يعاد استخدام رقم ملغى؛ تعديل السعر لا
يغير أثراً مرحلاً؛ سياسة السعر المفقود وعمر آخر سعر معتمدان؛ وفصل التصحيح عن
فرق السداد وعن التقييم مع ربط الآثار بالمراحل اللاحقة.
