# Phase 19 — الموازنات وتوقع السيولة

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 08، 11، 12، 13، 16، و17 عند الانطباق

## الهدف

التخطيط والمقارنة دون خلط الموازنة أو التوقع بالأثر الفعلي.

## التسليمات

موازنات وإصدارات اعتماد حسب الحساب والفترة والفرع والأبعاد، فعلي وانحراف وربحية؛
سيناريوهات سيولة من المستحقات والشيكات والعهد والتمويل وجداول الدفع مع مصدر كل
توقع ودرجة تأكيده.

## القبول

الموازنة لا تولد قيداً؛ لا جمع فاتورة وشيك مخصص لها مرتين؛ الإهلاك ليس دفعاً
نقدياً؛ التمويل المنطبق يدخل التوقع؛ ومجموع تحليل الأبعاد يطابق الإجمالي.
