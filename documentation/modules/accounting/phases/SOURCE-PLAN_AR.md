# خطة إنشاء موديول الحسابات من الصفر — Phases

الإصدار: 1.0  
التاريخ: 2026-09-08  
الحالة: خطة تنفيذ مستهدفة؛ جميع المراحل لم تبدأ.  
الاستخدام: وثيقة مستقلة قابلة للنقل لأي مشروع أو بيئة تنفيذ، دون الاعتماد على المشروع السابق أو كوده أو مهامه.

## هدف الإصدار وحدوده

إنشاء نظام حسابات للشركات والفروع يشمل دليل الحسابات، الشركاء، الأبعاد، العملات، القيود، الأستاذ المساعد، النقدية والبنوك، الفواتير والضرائب، الشيكات، المصروفات والعهد، الأصول والإهلاك، المؤجلات، التمويل عند انطباقه، التقارير والموازنات والإقفال.

الويب والموبايل مطلوبان للقدرات الوظيفية، بما فيها تحرير مصمم القوائم بواجهة مناسبة لكل منصة. أي اختلاف أو تأجيل يسجل صراحة مع صاحبه وشرط إعادة فتحه. الترحيل المالي دون اتصال غير مشمول.

المخازن والتصنيع وHR والرواتب وCRM وPOS ودورات الطلب والاستلام والتسليم خارج الإصدار. الفواتير مالية ولا تنشئ تكلفة مخزون أو حركة كمية. عند وجود مخزون فعلي يلزم مصدر خارجي موثوق ومطابقة قبل اعتماد القوائم. التجميع المالي المعقد والتأجير المتخصص والمشتقات تتطلب نطاقًا منفصلًا إذا احتاجها النشاط.

## قواعد تنفيذ مشتركة

1. لا افتراض لوجود تسجيل دخول أو صلاحيات أو قاعدة بيانات أو مكونات جاهزة؛ تفحص البيئة الجديدة أولًا.
2. محرك ترحيل مركزي؛ كل قيد مرحل متوازن، وتصحيحه بأثر جديد مرتبط دون تعديل أو حذف الماضي.
3. مبالغ decimal بدقة وتقريب معلنين؛ فصل تاريخ المستند والمحاسبة والاستحقاق.
4. تثبيت نسخ الحسابات والقواعد والأسعار والأبعاد عند الترحيل.
5. معاملات وقيود قاعدة بيانات وحماية تزامن ومفاتيح منع تكرار؛ انقطاع الاتصال ليس دليل فشل العملية.
6. عزل المستأجر والشركة والفرع حسب النموذج المعتمد في API والتقارير والملفات والمهام الخلفية، وإعادة التحقق عند التنفيذ.
7. فصل الإنشاء والاعتماد والترحيل والعمليات الحساسة. تغيير بيانات مؤثرة يبطل الاعتماد السابق.
8. الأستاذ المساعد يحمل تفاصيل الأشخاص والأصول؛ لا حساب أستاذ مستقل لكل شخص أو أصل.
9. الأحداث الخارجية بعد نجاح المعاملة بآلية إرسال موثوقة، مع إعادة محاولة تمنع التكرار.
10. القواعد المالية على الخادم؛ API مشترك للويب والموبايل، ومكونات واجهات مشتركة وترجمة عربية/إنجليزية وRTL.
11. لا اعتماد لسياسة ضريبية أو إهلاك أو شيكات من أمثلة الوثيقة؛ تعتمد سياسات الدول والنشاط قبل استخدامها.
12. فحوص المطابقة تبدأ مع محرك القيود وتضاف لكل مصدر؛ لا تؤجل للنهاية.

## Phase 00 — التحليل وتثبيت النطاق

**الهدف:** تحويل المتطلبات إلى قرارات قابلة للتنفيذ والاختبار.

**النطاق والتسليمات:**
- تحديد النشاط والدول والشكل التنظيمي ونموذج المستأجرين والشركات والفروع.
- اعتماد العملات والسنة والفترات، السياسات المحاسبية، مسؤول الاعتماد، وانطباق الشيكات والتمويل والمخزون الخارجي.
- اختيار التقنية وقاعدة البيانات والاستضافة والمنصات وتوثيق أسباب الاختيار.
- خريطة الدورات، قاموس المصطلحات، نموذج بيانات أولي، مصفوفة الأدوار، وسجل قرارات ومخاطر.
- حدود أداء رقمية: حجم القيود، عدد المستخدمين المتزامنين، زمن التقارير والترحيل والاستيراد؛ وسياسة RPO/RTO والاحتفاظ.

**القبول:** لكل قرار قيمة معتمدة أو مالك وموعد وبوابة تمنع استخدامه قبل الحسم. لا مدة تنفيذ مفترضة دون تقدير الفريق.

- [ ] اعتماد النطاق والقرارات ومتطلبات الأداء وخطة التسليم.

## Phase 01 — الأساس التقني والأمني

**الهدف:** منصة صالحة لبناء الدورات المالية. **تعتمد على:** 00.

**النطاق والتسليمات:**
- هيكل التطبيقات وAPI وقاعدة البيانات وإدارة migrations وبيئات التطوير والاختبار والإنتاج وCI.
- الدخول والجلسات والمستخدمون والأدوار والشركات والفروع وتفويض الوصول.
- سجل تدقيق، مرفقات محمية، سياسة احتفاظ ومنع فقد أدلة المستندات، ومهام خلفية وإشعارات موثوقة.
- مكونات نماذج وجداول وحوارات وصلاحيات وحالات تحميل وخطأ، مع العربية والإنجليزية وRTL.
- نسخ واستعادة ومراقبة أخطاء وإدارة أسرار وشركة تجربة معزولة.

**القبول:** اختبارات API وقاعدة بيانات فعلية لعزل شركتين ومستأجرين، بما فيها الملفات والمهام الخلفية. استعادة تجريبية ناجحة ومقاسة. عدم الاكتفاء بإخفاء أزرار الواجهة كحماية.

- [ ] الأساس والخوادم والمنصتان جاهزة، والعزل والاستعادة مثبتان.

## Phase 02 — التهيئة ودليل الحسابات

**الهدف:** بناء الهيكل المحاسبي. **تعتمد على:** 01.

**النطاق والتسليمات:** شجرة الحسابات وتصنيفاتها وطبيعتها، حسابات المراقبة، مستويات الأكواد، العملة الأساسية، السنوات والفترات والأقفال، استيراد وتصدير ومعالج تأسيس بإصدارات ومعاينة.

**القبول:** منع الدورات وتكرار الأكواد والترحيل على التجميعي. هوية الحساب مستقلة عن كوده. الحساب المستخدم يؤرشف ولا يحذف؛ التعديلات لا تفسد التاريخ. لا تداخل غير مسموح للفترات. يثبت محرك 06 تطبيق القفل وقت الترحيل.

- [ ] الدليل والفترات وحزمة التأسيس معتمدة.

## Phase 03 — الشركاء والمجموعات

**الهدف:** توحيد أطراف التعامل وربطهم المحاسبي. **تعتمد على:** 02.

**النطاق والتسليمات:** العملاء والموردون وأطراف العهد، تعدد الأدوار، المجموعات، حسابات المراقبة والمقدمات، شروط الدفع، الحسابات البنكية، وقواعد ربط مؤرخة مع بيان سبب اختيار الحساب.

**القبول:** إضافة ألف شريك لا تنشئ ألف حساب أستاذ. تغيير المجموعة لا يغير الماضي. تعديل حساب مورد البنكي له اعتماد مستقل. المعاملة الضريبية منفصلة عن مجموعة الشريك.

- [ ] بيانات الشركاء وروابطها وصلاحياتها مختبرة.

## Phase 04 — الأبعاد والتوزيعات

**الهدف:** تحليل مالي دون تضخيم القيم. **تعتمد على:** 02، 03.

**النطاق والتسليمات:** أبعاد معرفة بالمستخدم وقيم مسطحة/شجرية، إلزام مشروط بالحساب والمستند والفترة، قواعد توزيع بإصدارات وأولوية، محرر نسب ومبالغ، توزيع مركب، وتصحيح تحليلي مستقل يحفظ الأصل.

**القبول:** كل توزيع يطابق أساسه مع تقريب حتمي. غير المصنف لا يختفي من الإجمالي. مصروف 1,000 موزع أقسامًا 600/400 ومشروعات 700/300 لا يسمح باستنتاج تقاطع بضرب النسب؛ يحفظ تقاطع معتمد أو يعلن عدم توفره. الفرع التحليلي لا يتجاوز التفويض الحقيقي.

- [ ] عقد الأبعاد والتوزيع والتاريخ جاهز لاستهلاك محرك القيود.

## Phase 05 — الدفاتر والعملات والترقيم

**الهدف:** توحيد تعريف المستند وسعره ورقمه. **تعتمد على:** 02.

**النطاق والتسليمات:** دفاتر بأنواع وحسابات وصلاحيات، سلاسل ترقيم مؤرخة وحجز آمن، العملات والدقة واتجاه السعر ومصدره، أسعار يومية واستيراد وتجاوز بسبب ومعاينة أثر التعديل.

**القبول:** طلبان متزامنان لا يأخذان نفس الرقم. لا إعادة استخدام رقم ملغى. تعديل سعر لا يغير أثرًا مرحلًا. اعتماد سياسة السعر المفقود وعمر آخر سعر. فصل التصحيح عن فرق السداد وعن التقييم؛ تنفيذ آثارهما في 07 و20.

- [ ] عقود الرقم والسعر والتقريب مستقرة ومختبرة.

## Phase 06 — محرك القيود والاعتماد

**الهدف:** مصدر موحد للأثر المالي. **تعتمد على:** 03، 04، 05.

**النطاق والتسليمات:** قيد يدوي وآلي، معاينة واعتماد وترحيل، تحقق الحساب والفترة والأبعاد والتوازن، منع التكرار والتزامن، إلغاء المسودة وعكس وتصحيح المرحل، روابط المصدر والأثر، سجل تدقيق وفحوص الأثر المتوقع والمفقود.

**التقسيم الداخلي:** 06A عقود وحالات ومحرك؛ 06B موافقات وتصحيح؛ 06C فحوص وإصلاح مؤهل بمعاينة واعتماد وإعادة فحص.

**القبول:** لا تعديل/حذف مرحل أو Unpost. إعادة الطلب لا تكرر القيد. الأصل والعكس يظهران بحسب تاريخيهما. Backfill لا يخمن مصدرًا أو يتجاوز فترة أو يعدل قيدًا قائمًا. الإشعارات لا تسبق نجاح المعاملة.

- [ ] المحرك ينجح تحت التزامن والفشل وإعادة المحاولة.

## Phase 07 — الأستاذ المساعد والافتتاحيات

**الهدف:** ربط تفاصيل الذمم بالأستاذ. **تعتمد على:** 06.

**النطاق والتسليمات:** مستحقات وشروط وأقساط، تخصيص جزئي وكامل وعكس مؤرخ، فروق عملة محققة، خصم وشطب معتمدان، افتتاحيات حسابات وشركاء وأبعاد، أعمار تاريخية ومتابعة ديون.

**القبول:** تطابق التفاصيل وحساب المراقبة دون تحميل مزدوج؛ منع تخصيص زائد أو متزامن؛ الأعمار تعكس الحالة في التاريخ المطلوب. القسط لا يكرر الإيراد. فروق السداد تنشأ عند التسوية، وتتكامل المدفوعات الفعلية في 10. فتحيات الأصول والشيكات تستكمل عند بناء سجلاتهما.

- [ ] المستحقات والافتتاحيات والتخصيص والمطابقة مختبرة.

## Phase 08 — التقارير الأساسية

**الهدف:** إتاحة المطابقة مبكرًا. **تعتمد على:** 07.

**النطاق والتسليمات:** اليومية والأستاذ وميزان المراجعة وكشوف الشركاء والأعمار، دخل ومركز مالي أوليان، فلاتر الشركة والفرع والفترة والأبعاد، الانتقال إلى المصدر، وطباعة وتصدير من نفس البيانات.

**حد المرحلة:** تقارير أساسية وقوالب أولية؛ المصمم القابل للتحرير وتعدد إصداراته والتدفقات والتغيرات في حقوق الملكية تسليم 18.

**القبول:** أرقام قابلة للمطابقة مع القيود. PostedOnly افتراضي. المسودات معاينة معلنة لا تعتمد للإقفال ولا تحتسب مرتين عند ترحيلها. ثبات لقطة التقرير وصلاحيات بياناتها.

- [ ] التقارير الأساسية تحقق مطابقة كاملة على بيانات التجربة.

## Phase 09 — محرك الضرائب وعقد البلد

**الهدف:** تثبيت حساب الضرائب قبل بناء الفواتير. **تعتمد على:** 03، 05، 06.

**النطاق والتسليمات:** معاملات وقواعد ضريبية مؤرخة، إعفاء واسترداد وخصم/حجز عند انطباقها، حسابات وأساليب تقريب، عقد حساب البنود والمقدمات والإشعارات، وحقول البلد اللازمة للتكامل اللاحق.

**القبول:** حالات حساب متفق عليها مع المحاسب لكل بلد، وحفظ نسخة المعاملة. غياب سياسة لازمة يمنع استخدام المسار الخاضع. لا ادعاء جاهزية إرسال إلكتروني قبل 14.

- [ ] محرك الضرائب وعقد المستندات معتمدان.

## Phase 10 — الخزينة والبنوك

**الهدف:** تسجيل النقدية وتسويتها. **تعتمد على:** 07.

**النطاق والتسليمات:** خزائن وبنوك ووسائل دفع، قبض وصرف وتحويل ومقدمات وعمولات، جرد وتسوية فروق، استيراد كشف ومنع تكراره، نماذج مطابقة بمعاينة وأولوية واعتماد، ومبالغ معلقة.

**القبول:** فصل واقعة الدفع والتخصيص والتأكيد البنكي. لا تكرار أثر عند إعادة الكشف. المطابقة الملتبسة تتطلب مراجعة. التحويل لا يخلق نقدية جديدة. التكامل مع فروق العملة والتخصيص صحيح.

- [ ] النقدية والبنك والمطابقة متوازنة وقابلة للتتبع.

## Phase 11 — الفواتير المالية

**الهدف:** دورة فاتورة إلى سداد وتصحيح. **تعتمد على:** 09، 10.

**النطاق والتسليمات:** فواتير عملاء وموردين للخدمات والمصروفات والأصول، بنود مالية، مقدمات وأقساط، إشعارات ومرتجعات مالية جزئية/كلية، حد ائتمان، منع تكرار فاتورة المورد، طباعة ومرفقات وروابط المستحق والسداد.

**القبول:** إثبات الإيراد/المصروف/الأصل والذمة مرة واحدة. الإشعار لا يعني رد نقدية تلقائيًا. لا حركات مخزون. نجاح الاختبار الداخلي لا يسمح بإطلاق مستند خاضع قبل متطلبات 14.

- [ ] دورة الفاتورة والضرائب والسداد والتصحيح مختبرة.

## Phase 12 — المصروفات والعهد

**الهدف:** ضبط الطلب والصرف والتسوية. **تعتمد على:** 09، 10.

**النطاق والتسليمات:** طلب مصروف/عهدة، اعتماد وصرف، مطالبات ومستندات، أبعاد وضرائب، رد متبقٍ أو سداد فرق وإغلاق، وكشف عهد مفتوحة. ربط الفاتورة القائمة عند استخدامها لمنع إثباتها ثانية.

**القبول:** صرف عهدة لا يثبت مصروفًا نهائيًا ثم يعيده عند التسوية. فصل ما دفعه الطرف عن ما دفعته الشركة. كل تصحيح يطابق حساب الطرف والنقدية والأدلة.

- [ ] الطلب والمطالبة والتسوية والإلغاء مترابطة ومختبرة.

## Phase 13 — الشيكات

**الهدف:** دورة وارد وصادر كاملة. **تعتمد على:** 10.

**النطاق والتسليمات:** سجل ودفاتر وأرقام بنكية مستقلة عن الرقم الداخلي، استلام/إصدار، حيازة وإيداع وتأكيد ورفض وارتداد، إيقاف واستبدال وتظهير عند انطباقه، أحداث وحسابات وسيطة ومطابقة وتنبيهات.

**التقسيم الداخلي:** 13A السجل والحالات؛ 13B التأكيد والارتداد؛ 13C الاستبدال والتظهير والمتابعة.

**القبول:** فصل حالة المستند والحيازة وتأكيد البنك وتخصيص الذمم مع منع التركيبات المستحيلة. استلام شيك لا يزيد بنكًا مؤكدًا. الارتداد يحفظ تاريخ التسوية ويعالج الأثر المناسب. الاستبدال لا يكرر الالتزام. التحصيل الجزئي مشروط بسياسة معتمدة.

- [ ] كل انتقال مسموح له صلاحية وأثر واختبار وتصحيح.

## Phase 14 — الإقرارات والتكامل الإلكتروني

**الهدف:** استكمال جاهزية الدولة. **تعتمد على:** 09، 11، 12.

**النطاق والتسليمات:** خرائط الإقرار وأساس/مبلغ الضريبة، الفترات والمطابقة، الاعتماد والتقديم والسداد والتصحيح؛ التكامل الإلكتروني الإلزامي والتوقيع والمعرفات والردود وإعادة المحاولة وحفظ الأدلة.

**القبول:** مطابقة الإقرار مع المصدر والأستاذ. لا إعلان نجاح أو إلغاء خارجي دون إثبات. المفاتيح محمية على الخادم. السيناريوهات المعتمدة تشمل الفواتير والمقدمات والإشعارات والمصروفات. عدم انطباق تكامل يوثق حسب البلد.

- [ ] جاهزية البلد مثبتة قبل تشغيل المستندات الخاضعة.

## Phase 15 — الأصول والإهلاك

**الهدف:** دورة أصل مالية كاملة. **تعتمد على:** 11، 14.

**النطاق والتسليمات:** مجموعات وبطاقات ومكونات، أصل تحت الإنشاء وغير قابل للإهلاك، اقتناء وافتتاحيات وربط فاتورة ورسملة، تكلفة ومجمع وانخفاض، سياسة وعمر وقيمة تخريدية وجاهزية، جداول بإصدارات، دفعات إهلاك، تحسين ونقل وتغير تقدير وتصرف جزئي/كلي وتصحيح.

**التقسيم الداخلي:** 15A السجل والاقتناء؛ 15B الجداول والدفعات؛ 15C التصرف والتغيرات والمطابقة. طرق الإهلاك والانخفاض وإعادة التقييم تفعل وفق سياسة معتمدة.

**القبول:** بطاقة مرتبطة بقيد شراء لا تعيد التكلفة؛ افتتاح لا يعيد أقساط الماضي؛ هوية القسط تمنع تكراره عبر نسخ الجدول؛ سباق الإهلاك والتصرف محمي. مثال تجريبي: 120,000 تكلفة و12,000 تخريدية و36 شهرًا كاملًا بقسط ثابت = 3,000 شهريًا، وبعد سنة قيمة دفترية 84,000.

- [ ] السجل والتكلفة والمجمع والقيمة الدفترية تطابق الأستاذ.

## Phase 16 — الاستحقاقات والمؤجلات

**الهدف:** فصل الاعتراف المالي عن الدفع. **تعتمد على:** 11، 14.

**النطاق والتسليمات:** جداول مصروفات وإيرادات مؤجلة، استحقاق وعكس مجدول، إصدارات ومعاينة واعتماد ودفعات، تعديل المستقبل والإنهاء وتصحيح الماضي وربط المصدر والأبعاد.

**القبول:** الموزع والمتبقي يطابقان المصدر. الجدول لا يثبت دفعًا. إعادة التشغيل لا تكرر القيد. الفترة المقفلة تمنع الترحيل ولا تنقل التاريخ خفية. إلغاء المصدر يفحص الاعترافات اللاحقة.

- [ ] الجداول والأثر الدوري والعكس والمطابقة مختبرة.

## Phase 17 — القروض والتسهيلات

**الهدف:** تغطية التمويل المنطبق. **تعتمد على:** 10.

**النطاق والتسليمات:** عقد وجدول أصل وفائدة ورسوم، سحب وسداد وتسوية، إعادة جدولة وسداد مبكر وتصنيف قصير/طويل، وربط البنك والاستحقاقات وتوقع السيولة.

**القبول:** أصل القرض منفصل عن الإيراد والمصروف؛ الجدول لا يسجل دفعًا لم يحدث؛ التصحيح لا يحذف قيودًا مرحلة. إذا لا ينطبق التمويل يوثق قرار N/A وأدلته وصاحب القرار بدل الادعاء بتنفيذ الوظيفة.

- [ ] التمويل منفذ ومختبر أو عدم انطباقه معتمد.

## Phase 18 — مصمم القوائم وحزمة التقارير

**الهدف:** قوائم قابلة للتصميم والاعتماد. **تعتمد على:** 08، 13، 14، 15، 16، و17 عند انطباقها.

**النطاق والتسليمات:** مصمم مستقل على المنصتين، بنود شجرية وروابط حسابات ومعادلات آمنة وأعمدة ومقارنات، قوالب متعددة ونشر وإصدارات وأرشفة، دخل ومركز مالي وتدفقات مباشرة/غير مباشرة وتغيرات حقوق الملكية، إيضاحات وحزمة أدلة وتصدير.

**التقسيم الداخلي:** 18A المحرر والنسخ؛ 18B القوائم والتدفقات؛ 18C المقارنات والأدلة والتصدير.

**القبول:** منع دورات المعادلات وتداخل الربط وتكرار الإجمالي وتسريب البيانات. لا SQL أو كود حر. عدم احتساب نتيجة السنة مرتين قبل/بعد الإقفال. التقرير المعتمد يحفظ نسخة القالب والفلاتر والبيانات؛ الشاشة والملف متطابقان.

- [ ] المصمم والقوائم الأربع والتدفقات معتمدة ومختبرة على المنصتين.

## Phase 19 — الموازنات وتوقع السيولة

**الهدف:** التخطيط والمقارنة دون خلطه بالفعل. **تعتمد على:** 08، 11، 12، 13، 16، و17 عند انطباقها.

**النطاق والتسليمات:** موازنات وإصدارات اعتماد حسب حساب وفترة وفرع وأبعاد، فعلي وانحراف وربحية، سيناريوهات سيولة من مستحقات وشيكات وعهد وتمويل وجداول دفع مع مصدر كل توقع ودرجة تأكيده.

**القبول:** الموازنة لا تولد قيدًا فعليًا. لا جمع فاتورة وشيك مخصص لها مرتين. الإهلاك ليس دفعًا نقديًا. التمويل المنطبق يدخل التوقع. مجموع تحليل الأبعاد يطابق الإجمالي.

- [ ] الفعلي والموازنة والتوقع مستقلون ومطابقون لمصادرهم.

## Phase 20 — المراجعة والإقفال

**الهدف:** إقفال قابل للتدقيق. **تعتمد على:** الدورات المنطبقة من 08 إلى 18.

**النطاق والتسليمات:** مركز فحوص للمفقود والمكرر وغير المتوازن والروابط والأبعاد والذمم والبنوك والشيكات والأصول والضرائب؛ تقييم العملات المؤهلة والتسويات؛ إصلاح أثر مفقود مؤهل؛ معاينة واعتماد وتنفيذ ونتائج عناصر وإعادة فحص؛ أقفال فترات وسنة وحزمة مراجعة.

**القبول:** لا اعتماد على فحص قديم؛ حاجز كتابة يغطي الترحيل والعكس والتخصيص والدفعات عند الإقفال. لا تجاوز مانع حسابي/أمني. المعلقات المشروعة تصنف وتفسر ولا تصفر قسرًا. لا افتتاحيات سنوية مزدوجة للحسابات الدائمة. فشل PDF لا يعيد الأثر المالي. نقص معلومات تاريخية يعالج يدويًا باعتماد، لا بالتخمين.

- [ ] إقفال تجريبي ومطابقة قبل/بعد مع منع السباق والازدواج.

## Phase 21 — النقل واعتماد التشغيل

**الهدف:** إطلاق مثبت بالأدلة. **تعتمد على:** 19، 20.

**النطاق والتسليمات:** خرائط وقوالب نقل وتجارب استيراد، افتتاحيات وتفاصيل شركاء وأصول ومجمع وشيكات وأبعاد وجداول، خطة قطع تشغيل ورجوع، اختبار دورة كاملة، أداء وأمان واستعادة، تدريب ودليل تشغيل ومسؤول دعم واعتماد نهائي.

**القبول:** تطابق الأستاذ والتفاصيل وعدم ازدواج الافتتاحيات. استعادة تعيد الملفات والروابط وحالات منع التكرار وتحقق RPO/RTO المعتمدين. حدود الأداء من 00 ناجحة على حجم ممثل. جميع الدورات المطلوبة والمنصتان معتمدة، والمشكلات المتبقية مصنفة دون مانع تشغيل مفتوح.

- [ ] اعتماد المحاسب وصاحب المشروع ومسؤول التشغيل موثق.

- [ ] مرفقات وتدقيق وتقارير وتصحيح متاحة حيث تنطبق.
- [ ] دليل التشغيل والقيود المعروفة محدث.
- [ ] المراجع اعتمد التسليم بالأدلة؛ وجود شاشة أو ملف وحده لا يثبت الإنجاز.

## سيناريو قبول نهائي متكامل

تشغيل شركة تجربة من افتتاحيات إلى فاتورة وضريبة وسداد جزئي، ثم شيك وارتداد، وعهدة وتسويتها، وأصل وإهلاكه والتصرف فيه، وحركة بعملة أجنبية وتسويتها وتقييم المفتوح، وجدول مؤجل وتمويل عند انطباقه. اختبار التصحيح والأبعاد والتقارير والموازنة والتوقع والإقفال، ثم الاستعادة ومطابقة الأرصدة والتفاصيل والأدلة. تشمل الاختبارات إعادة الطلب وفشل دفعة وطلبين متزامنين والوصول غير المصرح به.

هذه الوثيقة تخطيط للتنفيذ الجديد ولا تثبت تنفيذ أي وظيفة أو اعتماد سياسة محاسبية محلية. أي تغيير نطاق يحدث في هذه النسخة وسجل القرار والمرحلة المتأثرة معًا.
