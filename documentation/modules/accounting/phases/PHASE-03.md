# Phase 03 — الشركاء والمجموعات

**الحالة:** Planned / Not started · **الاعتماديات:** Phase 02

## الهدف

توحيد أطراف التعامل وربطهم المحاسبي دون تضخيم دفتر الأستاذ.

## التسليمات

العملاء والموردون وأطراف العهد وتعدد الأدوار والمجموعات وحسابات المراقبة
والمقدمات وشروط الدفع والحسابات البنكية وقواعد ربط مؤرخة مع سبب اختيار الحساب.

## القبول

إضافة ألف شريك لا تنشئ ألف حساب أستاذ؛ تغيير المجموعة لا يغير الماضي؛ تعديل
حساب المورد البنكي له اعتماد مستقل؛ والمعاملة الضريبية منفصلة عن مجموعة الشريك.
