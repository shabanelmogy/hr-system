# ReferenceData web client documentation

ReferenceData has active Next.js surfaces under `web-next/src/modules/reference-data`.
Current routed capabilities include Address Types plus Countries, States, and
Districts. Their public URLs and exact App Router ownership are kept in the
generated frontend architecture manifest. New ReferenceData features must still
document their server/client boundary, loading/error/empty states, permissions,
localization, and verification before release.

The generated current ownership/route inventory is maintained in
`documentation/web-next/architecture/frontend-architecture-manifest.md`.
