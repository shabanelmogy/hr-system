## Current behavior and ownership

Platform owns the typed catalog schema, credentialed finite read service, client presentation registry, scoped signal state and pages. Unknown/malformed/duplicate identities are rejected. Server purchase/permission membership is intersected with the five reviewed client module definitions; a local registry never supplies a grant. Server entryPath is parsed but never used as a route or external URL. Registered Angular area routes show the existing truthful modules.noAvailableFeatures empty state until their independent business child is ported. This does not implement those business workflows. Administration CRUD links remain absent.

Current Next route policy excludes global super_admin from the tenant application workspace. Both visible actions and direct callbacks retain that exclusion; direct /apps entry shows Forbidden and performs zero catalog requests. Normal/admin sessions use the existing server catalog. No new permission, API endpoint, business entity, schema or migration is introduced. Canonical core adds eight EN/AR module/area labels; their generated API catalog preserves the existing SQL-backed override mechanism. API was rebuilt/restarted for the embedded catalog, with no endpoint/security/source behavior change.

ModuleWorkspace provides the catalog state for its own component lifetime. One observable subscription owns the read; concurrent consumers share signals. Identity changes synchronously mask old data and switchMap cancels the prior HTTP subscription; component destruction also cancels. Loading, retry/error, denial and empty never expose stale data. Source currentColor language/theme behavior remains intact.

Shared LauncherGrid/LauncherTile own responsive tile layout, accessible links/focus and canonical colors/icons; FeedbackState owns loading/error/empty/forbidden semantics and retry action presentation. ApplicationFrame gains generic navigationVisible for source /apps sidebar suppression. Shell and feature pages compose these shared public APIs. Cards have native keyboard/link semantics and logical RTL arrows. Source Material icons retain their accompanying MIT license. Splitting the generic tile from its grid keeps each actual component style below the existing 4kB warning budget; budgets are unchanged.

## Research and resolved findings

Scoped cancellation and request validation follow [Angular HTTP](https://angular.dev/guide/http/making-requests); typed HttpClient alone does not validate response data. Reactive route params follow [Angular route state](https://angular.dev/guide/routing/read-route-state). The synchronous identity mask covers the documented asynchronous signal-to-observable boundary; one scoped subscription handles cleanup, avoiding a second auth store. Client presentation/guards only narrow the actual server authority, as [Angular route guards](https://angular.dev/guide/routing/route-guards) requires.

Source audit surfaced the independent global-role route exclusion; the initial server-only membership model was tightened before acceptance. A live test's Applications locator matched both sidebar and body action; the test now scopes the intended action to main. No UI behavior was changed to satisfy an ambiguous test selector. Angular development HMR retained an old compile error after a dependency edit; a clean own-process restart with documented --hmr=false/--poll 1000 restored builds and subsequent source edits produced automatic page reloads. See [Angular CLI serve](https://angular.dev/cli/serve). Production builds and their independently served acceptance passed separately.
