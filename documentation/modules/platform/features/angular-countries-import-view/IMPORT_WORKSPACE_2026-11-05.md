## 1. النطاق المعتمد

طلب المستخدم تحسين مكونات تاب Import ورسائل أخطائه، ثم تقليل المساحة المستهلكة بالتفاصيل: كروت عمودية، وأزرار في صف العنوان عند الجهة المقابلة، وكارت بارتفاع الشاشة المتاح، وفاصل خفيف بين الإحصائيات والجدول، وزيادة عرض عمود الكروت لتفادي التفاف آخر حرف من VERIFICATION. هذه صيانة للعرض والتشخيص ضمن Countries Import الحالي S3-A7، وليست وظيفة استيراد جديدة.

## 2. التصميم والملكية

يملك `SpreadsheetImportPanel` الشكل العام القابل لإعادة الاستخدام. يعيد استخدام `SurfaceCard` مع `compact` و`fill` وقالب رأس البطاقة، و`ActionButton` و`StatusBadge` و`MetricCard` و`FeedbackState`. يضم الرأس اختيار الملف وتنزيل القالب والإفراغ والرفع، عند inline-end مقابل العنوان. يكون عمود الحالات الرأسي عند inline-end بعرض11.5rem وفاصل من متغير border؛ تتكيف الجهة مع RTL. أضيف إلى MetricCard خيار `compact` اختياري افتراضيهfalse، لتوفير صف قصير للنص والأيقونة والقيمة دون التأثير على بقية المستهلكين.

توجد تفاصيل نوع الملف وحدود5MiB/100صف والعناوين في disclosure يمكن فتحه بلوحة المفاتيح. يبقى اسم الملف وعدده مرئيين. تستعمل الأزرار المساعدة أيقونات مسماة على الهاتف عبر ActionButton القائم. لا إيهام بسحب وإفلات غير منفذ. يبقى PrimeNG FileUpload في basic/custom mode لاختيار محلي؛ parser الحالي هو مالك التحقق من الملف.

يمتد كارت Import داخل المساحة المتاحة في Countries؛ لا حسابات بطرح أرقام ثابتة من viewport. تبقى سلسلة flex/min-height:0 من مضيف الميزة إلى SurfaceCard والجدول، ويجري التمرير في Table. على الشاشات الضيقة تسبق المعاينة عمود الحالات القابل للتمرير والمحدود الارتفاع؛ يصبح الفاصل أفقيًا. تبقى مساحة فعلية لصفوف البيانات وشريط paging. لا CSS خاص بالدول لتكرار سياسة العرض؛ مضيفها يحدد ارتباطها بحاوية الصفحة فقط.

## 3. التشخيص والتصحيح

تبقى `countryFieldError` السلطة الوحيدة لقواعد الحقول. تحمل الصفوف `issues` typed إلى جانب `errors` المتوافق مع العقد السابق. الرسائل توضح المطلوب فعليًا: اسم مفقود، اسم أقصر من حرفين أو أطول من100، محارف تحكم، كود من حرفين/ثلاثة أو اتصال من أرقام مع + اختياري. يضيف العرض اسم الحقل ورقم صف Excel. تسجل خرائط التكرار الصف المقبول السابق فقط؛ لا تُنسب قيمة مكررة إلى صف رُفض أصلًا لسبب آخر.

تعرض أخطاء الملف طريقة التصحيح، ويضيف parser عنوان الخلية عندما يستطيع تحديدها، مثل صيغة Excel أو عمود زائد. يحتفظ تنزيل القالب برسالة فشل خاصة به. يكون التنبيه العلوي مختصرًا؛ تبقى تفاصيل كل صف كاملة في عمود Validation details.

تسمح `CountryService.bulkCreate` بمسارات أخطاء الخادم المحددة فقط من قائمة `countries[index].field` الفعلية. يبقى Shared classifier بمطابقة أسماء كاملة دون مطابقة suffix أو تمرير أخطاء مجهولة. تعيد `countryImportFailureRows` رقم العنصر المرسل إلى صف Excel الأصلي بعد استبعاد الصفوف غير الصالحة. تكرار الخادم `Country.Duplicated` (أو رمزالتوافق Country.CountryExists) رفض للدفعة؛ لا يُدعى أنه حدد صفًا بعينه. تعرض الصفوف الأخرى أنها لم تحفظ بسبب رفض الدفعة، بينما تفاصيل الصف المحدد تظهر فقط إذا ورد مسار معتمد من الخادم.

تبقى not-sent وrejected وuncertain حالات مختلفة. لا retry تلقائي ولا إعادة إرسال لدفعة ذات نتيجة غير مؤكدة؛ تستمر مراجعة السجلات والقفل والإفراغ الصريح كما كانت. تبقى صلاحيات Create وملكية الجلسة وإلغاء الطلبات وحماية مغادرة المعاينة كما هي. لا endpoints أو مخطط أو migrations أو اعتماديات جديدة.

## 4. الترجمة وحدود النشر

عُدّلت موارد EN/AR الأصلية تحت `web-next/src/locales/resources/core` و`reference-countries`، ثم أعيد توليد catalog API ونسخ Angular وfingerprint. لا تحرير يدوي للملفات المتولدة. تبقى نسخة Mobile وعقود أعمال API وNext كما هي؛ تعديلات Next هنا موارد نصوص مشتركة فقط. النشر المتطابق للكتالوج وعمليتيWeb والتحقق من overrides المستضافة يظل تحت PROD-019. لا تعد نتائج fixtures قبولًا لاستيراد بيانات إنتاج حقيقية.

## 5. التحقق

تعرض [النتيجة الحالية وبصمات المصدر](verification/IMPORT_WORKSPACE_2026-11-05.json) أدلة التنفيذ المحددة. لا تعني29حالة fixtures قبولًا لخادم أو قاعدة بيانات فعلية. حصل timeout واحد في اختبار Reporting موجود أثناء تزامن فحص كامل مع متصفح وخادم تطوير؛ نجح الفحص الكامل النهائي بعد إعادة تشغيله دون تلك الأحمال ودون تغيير مهلة الاختبار.

يستعمل سكربت `verify-country-import-browser.mjs --compact` حالاتEN/AR ×light/dark ×390/1440. يقيس صف العنوان، جهة الأزرار والإحصائيات، رأسية الكروت وحجمها، اتصال الكارت بأسفل viewport، ارتفاع مساحة الصفوف، الفاصل، وعدم انقسام كلمةverification. يحتفظ بحالات رفض الملف والدفعة وfield errors وuncertain والصلاحيات عبر `--focused`، ورحلات الاستبدال/المغادرة ولوحة المفاتيح عبر `--journeys`. جميع طلباتAPI الكتابية معترضة، دون كتابة حقيقية. تسجل نتيجة الصيانة الحالية الأوامر والنتائج النهائية والقيود؛ تبقى أدلة2026-10-31 بتاريخها ونطاقها.
