## Implemented bounded surface

- Native menu filters use strict typed text/number/date/boolean constraints,
  bounded rules, per-field AND/OR and Apply/Clear. Edits update PrimeNG's isolated
  filter constraint draft; its custom filterCallback would execute immediately,
  so it is deliberately not called while typing. Invalid vendor events reject the
  entire event. Zero, false and calendar dates retain their types.
- Controlled remote data stays unchanged until the owner returns a new page.
  Single-sort initialization is coalesced; multi-sort emits validated field lists.
  The neutral harness queries all 137 fixture rows before slicing its page.
- PageHeader.collection reuses shared actions/badges/icons and adapts the actual
  Next source title, gradient, spacing, compact badges and view toggles. Mobile
  badges occupy a separate full-width row; active overflow views stay visible.
  Source comparison for the actual Countries shell is still outstanding.
- The shared collection toolbar supports the measured reference layout without
  replacing its controller, feedback, paging, record navigation or options.
- Display supports gridlines, stripes, resize fit/expand, column order and optional
  direct column-management actions. Flex widths respect source header minimums.
- Multiple/single/radio/range selection remains current-page and eligibility bound.
  Shift-click/Shift-Space/Shift-Arrows extend a range, separate from active record.
- Frozen columns use logical edges mapped through RTL. Frozen rows are split from
  the supplied current page, never appended to totals. PrimeNG22.1.4 applies its
  frozen tbody class to both bodies; the shared scoped CSS keeps the ordinary
  body static. Empty frozen bodies are not installed.
- Subheader/rowspan grouping validates current-field values and contiguity. Global
  grouping requires a complete supplied set. Expandable subheaders are supported;
  grouped details, frozen grouped rows and expandable rowspan reject explicitly.
- Typed detail slots, owner current-row context actions, safe CSV and validated
  versioned presentation snapshots are implemented. Scope replacement clears
  details/menu/selection/presentation; the shared kit owns no browser persistence.
- PrimeNG captions flow through existing LocalizationRuntime and generated core
  resources, preserving runtime SQL overrides. No feature-local translation map.
