# CustomerRelationshipManagement web client documentation

CRM has an active Next.js surface. Appointments is currently implemented at
`/appointments` under `web-next/src/modules/crm` and registered through the CRM
module definition. Additional CRM capabilities remain feature-scoped work and
must document their route, server/client boundary, loading/error/empty states,
permissions, localization, and verification before release.

The generated current ownership/route inventory is maintained in
`documentation/web-next/architecture/frontend-architecture-manifest.md`.
