# HR web documentation

HR web behavior remains in the established `documentation/web-next/` feature
books until a manifest-aware migration is completed. This package owns the HR
index and module-specific decisions; it does not copy shared Next.js rules.

For each HR feature, verify route ownership, server/client boundaries,
permissions, loading/error/empty states, localization, and tests. A link in the
catalog does not imply that a web surface exists.
