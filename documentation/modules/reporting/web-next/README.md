# Reporting web client documentation

Reporting has an active Next.js surface. Crystal Reports management is currently
implemented at `/administration/crystal-reports` under
`web-next/src/modules/reporting`. Additional Reporting capabilities remain
feature-scoped work and must document their route, server/client boundary,
loading/error/empty states, permissions, localization, and verification before
release.

The generated current ownership/route inventory is maintained in
`documentation/web-next/architecture/frontend-architecture-manifest.md`.
