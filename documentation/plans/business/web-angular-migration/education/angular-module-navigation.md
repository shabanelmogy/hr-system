# التطبيقات والأقسام في Angular

للحساب العادي أو المدير، افتح التطبيقات من بطاقة الصفحة الرئيسية أو القائمة الجانبية، أو https://localhost:4210/apps بعد تسجيل الدخول. تظهر التطبيقات التي يسمح بها اشتراك وصلاحيات الجلسة الحالية. اختر التطبيق ثم القسم؛ يمكنك الرجوع للأب أو تحديث الصفحة داخل القسم. حساب Super Admin يحتفظ بمسار الإدارة المستقل مثل web-next.

القسم الذي لم تصبح له شاشة متاحة في مساحة العمل يعرض رسالة واضحة بدل رابط ميت أو بيانات أعمال تجريبية. نقل شاشات الأعمال ولوحات البداية والإدارة يتم بالتتابع. إذا تعذّر التحميل يظهر زر إعادة المحاولة؛ الرابط غير المسموح يعرض منع الوصول.

ألوان البطاقات والأيقونات ومقاساتها مأخوذة من web-next وتعمل مع العربية والإنجليزية والثيمات. أسماء الوحدات والأقسام في كتالوج الترجمة المركزي، وتظل تعديلات الترجمة المسجلة في قاعدة البيانات مطبقة حسب نطاق الجلسة. لا يُعرض مفتاح الترخيص أو رموز الجلسة في الواجهة.
