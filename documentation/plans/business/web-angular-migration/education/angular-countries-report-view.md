# تقارير الدول والطباعة PDF

Phase06 Verified2026-10-31; customer education follows verification.

من Dashboard Data افتح القائمة الجانبية ثم الدول، واختر Report من طرق العرض.
قد يكون الاختيار داخل قائمة طرق العرض على الهاتف. يلزم دور مدير النظام وصلاحية
عرض الدول وصلاحية GlobalCrystalReports:View؛ تقارير النظام العامة لا تحتاج تفعيل
موديول Reporting داخل شركة. وضع القراءة فقط يسمح بعرض التقرير.

لوحة التقرير تعرض الاسم العربي والإنجليزي ثم نموذج التقرير. هذه المعايير مستقلة
عن بحث الجدول والكروت. اكتب المعايير واضغط Search؛ تغيير اللغة أو نموذج التقرير
يستخدم آخر معايير طُبّقت. Clear Filters يمسح المعايير ويولّد التقرير من جديد.
حد كل حقل200حرف؛ الخطأ يظهر تحت الحقل وينتقل التركيز لأول حقل غير صالح.

زر الفلاتر في عنوان الشاشة يفتح لوحة المعايير ويغلقها دون مسحها أو إعادة توليد
التقرير. Refresh يقرأ النماذج المتاحة ومصدرها الحالي ويعيد التوليد. عند تغيير
ملف التقرير على السيرفر تظهر رسالة تطلب التحديث بدل تشغيل نسخة غير مؤكدة.

Open PDF يفتح الملف في تبويب مستقل للطباعة من عارض المتصفح. Download File ينزّل
نفس الملف. إذا كان المتصفح لا يدعم المعاينة المدمجة، تظهر رسالة ويظل الفتح
والتنزيل متاحين. عدم وجود نموذج منشور أو فشل التحميل يعرض حالة واضحة وإعادة محاولة.

الانتقال إلى Grid/Cards/Chart يلغي طلب التقرير الجاري ويحرر الملف السابق. الرجوع
إلى Report يبدأ معايير تقرير جديدة؛ معايير الجدول لا تتغير. تغيير الجلسة أو فقد
الصلاحية يخفي الملف السابق. لا يعاد طلب خطأ الصلاحية أو تعارض المصدر تلقائيًا.

هذه الخطوة لا تتضمن إنشاء أو تعديل تصميم RPT أو رفعه؛ التقرير يعتمد على النماذج
المتاحة في السيرفر. ActiveReports ملغى. الخطوة التالية استيراد XLSX ثم مراجعة
الدول كاملة على المصدر والهوست، بما فيها التطابق البصري النهائي.
