# دليل Settings واللغة والترجمة

من «Administration» افتح «Settings». تظهر تبويبات «System» و«Appearance» في مدخل واحد. تبويب System يعيد استخدام إعدادات الاحتفاظ بسجل الأخطاء وصلاحياتها، بينما Appearance يغير اللغة والنمط من المكوّن المشترك.

افتح «اللغة والترجمة» لاختيار مصدر نصوص واجهة النظام، واللغة الأساسية والمستهدفة، وحالة التخصيص. البحث وتقسيم الصفحات يعملان من API. اضغط تعديل لعرض النص الأساسي والأصلي وتغيير النص المستهدف، أو استعادة لإرجاع النص الأصلي بعد التأكيد. يجب الاحتفاظ بالمتغيرات مثل {{name}}، ويظهر الخطأ تحت الحقل عند مخالفتها. عند تعارض المراجعة حمّل أحدث الإعدادات قبل إعادة المحاولة. تفضيل لغة العرض والمظهر يظل في Settings وTopBar، وصلاحيات العرض والتعديل والاستعادة مستقلة.

Health Check وAPI Endpoints وHangfire Dashboard تحت Administration بصلاحياتها المستقلة. يتم فتح Swagger وHangfire داخل إطار محمي؛ تحقق CSP والنشر المستضاف مسؤولية Operations قبل الإصدار.
