# تسجيل الدخول في Angular

افتح https://localhost:4210/login. فتح العنوان الرئيسي ينقلك لصفحة الدخول أيضًا.
التصميم مأخوذ من صفحة web-next الحالية، مع العربية والإنجليزية والوضع الفاتح والداكن.

اكتب اسم المستخدم وكلمة المرور واضغط تسجيل الدخول. يمكن استخدام أزرار الحسابات
التجريبية الموجودة في بيئة التطوير؛ الطلب يمر بالـAPI الحقيقي. لو ظهر اختيار
المنشأة أو الشركة، اختر النطاق المطلوب ثم متابعة. الإلغاء يمسح الاختيار وكلمة المرور.

عند وجود أخطاء يظهر ملخص مشترك ببادج للعدد وبادج لكل حقل ورسالة الخطأ.
اضغط البادج للانتقال للحقل مباشرة؛ رسالة الخطأ موجودة تحته أيضًا.
البادجات تختفي تدريجيًا عند تصحيح القيم، وزر الدخول يظل متاحًا لتوضيح الأخطاء.

بعد نجاح الدخول تظهر بيانات الجلسة الحقيقية والمستخدم والشركة. تحديث الصفحة
يعيد التحقق من الجلسة، وزر تسجيل الخروج ينهيها. هذه خطوة الدخول فقط؛ نقل
لوحة التحكم والقائمة الرئيسية وشاشات الأعمال ما زال ضمن المراحل التالية.

رابط نسيان كلمة المرور يستخدم طلب الاسترجاع الحالي. زر Google يعرض رسالة
عدم الإتاحة لأن مزوده غير مفعّل في الـAPI الحالي. لا يلزم إدخال مفتاح PrimeUI
داخل صفحة الدخول. ترجمات قاعدة البيانات تُقرأ حسب صلاحيات ونطاق المستخدم؛
شاشة تحرير/حفظ الترجمات لها خطوة مستقلة في الخطة.

اختبارات هذه الخطوة تشمل الدخول الفعلي والتحديث والخروج، ومقارنة التصميم
مع web-next، وبادجات التحقق والتوجيه للحقول على الكمبيوتر والموبايل.
