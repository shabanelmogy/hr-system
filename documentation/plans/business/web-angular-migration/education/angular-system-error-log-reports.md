# دليل تقارير سجل الأخطاء واختبار المقاسات

افتح سجل أخطاء النظام، ثم اختر عرض التقرير. على الشاشة الصغيرة قد يكون ضمن
قائمة طرق العرض الإضافية. يتطلب العرض دور المشرف العام وصلاحيتي عرض السجلات
وعرض التقارير العامة معًا. تبقى صلاحيات تنزيل ورفع ونشر القالب مستقلة.

يحترم التقرير الفلاتر المطبقة في شاشة السجل عبر جميع النتائج. غير الفترة أو
الفلاتر من الشاشة، ثم اختر التقرير المطلوب. الحد خمسة آلاف سجل؛ ضيق الفلاتر
إذا تجاوزت النتائج هذا الحد. لا يضم التقرير التشخيصات الداخلية أو عنوان IP
أو معرّفات الشركة والمستأجر. إن لم يوجد قالب منشور، تظهر حالة عدم وجود تقرير
ولا يعرض التطبيق ملف PDF تجريبيًا على أنه تقرير حقيقي.

في مدير التقارير العامة اختر إنشاء قالب، ثم وحدة المنصة ومصدر سجل الأخطاء.
هذا المصدر جاهز من التطبيق ولا يحتاج اختيار SQL View. نزّل حزمة التصميم وأنشئ
قالب RPT حقيقيًا باستخدام مخطط XSD والحقول المحددة. ارفعه وافحصه ثم انشره صراحة.
تظل مصادر الجغرافيا مرتبطة باختيار View المتحقق منه كالمعتاد. لا تمنح تقارير
سجل الأخطاء لأدوار المستأجرين. تحقق خدمة Crystal والإصدار الفعلي وفق PROD-031.

أثناء التطوير يظهر مؤشر المقاسات في الشريط العلوي، مثل 1440 × 900 · lg.
الأرقام هي عرض وارتفاع نافذة العرض بوحدة CSS pixel وتتغير عند تغيير الحجم.
النطاقات: xs أقل من٦٠٠، sm من٦٠٠حتى٨٩٩، md من٩٠٠حتى١١٩٩، lg من١٢٠٠فأكثر.
استخدمه لمراجعة الواجهات عند حدود المقاسات. يختفي تلقائيًا في نسخة الإنتاج.
