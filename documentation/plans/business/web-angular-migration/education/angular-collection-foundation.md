# مراجعة أساس الجداول والكروت — S1-A3

الحالة: Phase06 Verified في2026-10-29. هذا دليل مراجعة وتسليم تقني؛ تدريب
عميل الأعمال N/A لأن الشريحة لا تضيف شاشة أعمال جديدة. تقرير التنفيذ والقياسات
والصور المقارنة محفوظة في documentation/modules/platform/features/angular-collection-foundation/.

من جذر المستودع شغل npm --prefix web-angular run start:host، ثم افتح
https://localhost:4210/dev/collections. يلزم Node المتوافق، مفتاح Community محلي
في .env.local وشهادات HTTPS. المعاينة على dev فقط وتُستبعد من build الإنتاج.
السيرفرات المؤقتة للفحص تُوقف بعد المراجعة؛ شغل سيرفرك بنفس الأمر عند الحاجة.

1. بدّل Grid/Cards واللغة والوضع واللون. راجع390 و1440px والتمرير داخل اللوحة.
2. جرّب البحث، اختيار الحقل والشرط، والفلتر. مالك الصفحة يثبت القيم ويطلب الصفحة؛
   المكون المشترك لا يفلتر صفحة خادم محملة محليًا. البيانات هنا37 سجلًا صناعيًا محايدًا.
3. فرّق بين السجل النشط وتحديد Checkbox. تحديد الكل يشمل السجلات المسموحة
   في الصفحة الحالية فقط. الإجراءات داخل الخلية لا تنقل السجل النشط.
4. جرّب أسهم السجلات وأسهم الصفحات وتغيير حجم الصفحة. End ثم ArrowDown يعبر
   الصفحة مع تركيز السجل المطلوب؛ Home/End للصفحة وCtrl+Home/End للكل حسب العدد.
   آخر سجل مع العدد المجهول غير متاح. Cards تحترم الاتجاه في الأسهم الأفقية.
5. Grid options تغيّر الكثافة والأعمدة، مع منع إخفاء العمود المحمي أو آخر عمود.
   تغيير السياق يعيد خيارات العرض والتحديد. Escape يقفل القائمة ويعيد التركيز.
6. أزرار الحالة العليا مخصصة للفحص: All جاهز، Unknown عدد مجهول، No data فارغ،
   Error ثم Retry، Access Denied، Loading، وLast لمحاكاة صفحة خارج النطاق عمدًا.
   Reset يبدّل نطاق البيانات الصناعي لإثبات عزل النتائج القديمة.

لا توجد CRUD أو Countries أو Chart/Import/Export في هذه المعاينة. تلك تبقى
رحلات مستقلة بعقودها. FOLLOW-016 يملك الخيارات المتقدمة وFOLLOW-014 باقي حقول
الأعمال والمحررات. أي مستهلك جديد يستخدم shared/ui/public-api ويملك API والبيانات
والصلاحيات والفرز والبحث والصفحات، ولا يعيد بناء شريط أو Grid محلي.

الترجمة ما زالت عبر كتالوج الواجهة الحالي وSQL. إصدار الكتالوج الجديد يحتاج
نسخة API متوافقة منشورة قبل قبول ترجمات الهوست؛ PROD-019 يملك هذا الفحص.
هذه المعاينة لا تطلب بيانات من API ولا تثبت حفظ ترجمة أعمال في قاعدة البيانات.
