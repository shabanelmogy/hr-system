# مراجعة حقل المراجع المشترك — S1-A4

Phase06 Verified بتاريخ2026-10-29. دليل تقني للتسليم والمراجعة؛ تدريب عميل
الأعمال N/A لأن هذه الشريحة لا تضيف شاشة أعمال. التقرير والنتائج والصور محفوظة
في documentation/modules/platform/features/angular-reference-selection-foundation/.

شغل npm --prefix web-angular run start:host ثم افتح
https://localhost:4210/dev/references. المعاينة متاحة في التطوير فقط، ببيانات
صناعية محايدة وبلا طلبات API. يلزم Node المتوافق والمفتاح والشهادات محليًا.

1. أول حقل قيمة91 خارج صفحة النتائج. افتحه وشاهد القيمة الحالية معطّلة
   للاختيار، ثم Load more. قيمته تظل موجودة أثناء البحث وتحميل الصفحات.
2. اختر0 ثم امسحه. Save يظل متاحًا ويعرض الخطأ تحت الحقل وفي الملخص ويركز
   أول حقل غير صالح. الحقل الثاني بقيمة نصية0 مستقل عن القيمة الرقمية0.
3. جرّب البحث السريع وIME، وعدم وجود نتائج، وEscape/Arrow/Enter والتركيز.
   البحث من داخل القائمة لا يرسل النموذج. النص الطويل لا يوسع الصفحة.
4. جرّب View Only وتعطيل الحقل وReset وEdit Information للتعبئة البرمجية.
   زر أخطاء التحقق يحاكي خطأ خادم؛ التغيير الصحيح يمسحه، والخيار المعطّل لا يفعل.
5. حالات Error/Retry وAccess Denied والمرجع المفقود/المؤرشف منفصلة. القيمة
   المفقودة لا تتحول إلى تسمية رقمية مصطنعة. صلاحية المرجع يقررها مالك المجال.
6. بدّل الفلتر الأب A/B: مالك النموذج يعيد قيمة الحقل صراحة، والمشترك يحجب
   نتائج وتسميات الأب القديم. اختبر العربية والوضعين و390/1440px.

المستهلك يستخدم ReferenceField والأنواع من shared/ui/public-api، ويملك طلبات
الخادم والتحقق والصلاحيات والبحث والصفحات وحل القيمة المحفوظة. لا ترجع إلى
Dropdown محلية ولا تعدّل OptionSelect الخاصة بالهيدر لتقوم بدور حقل أعمال.
استمرار قيمة خارج الصفحة لا يثبت حق الوصول إليها أو صلاحيتها للعملية.
