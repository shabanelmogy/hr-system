# Company email templates — Pre-plan specification

Company administrators customize three registered account templates independently: confirmation/reset/invitation. en/ar subject/body, safe variables, formatted editor, sample preview, save/reset and revision/audit form one workflow under Administration > Email Templates. Web edits/previews; Mobile lists/previews only, explicitly selected.
Trusted company/persisted invitation binds customization; missing company uses shipped defaults. Existing server action URLs and one intended recipient remain protected. CC/BCC, arbitrary templates, campaigns, images/tracking, HTML source mode and external test sends are Excluded in S1. New business uses add definitions and bindings when needed. HR retains its settings.
Existing shared Grid/form/navigation/feedback are mandatory; only a generic rich-text field is missing. Privacy: sample preview, no real tokens/logs/extra recipients. Existing SMTP/provider configuration retained. All high-cost questions answered; culture assumption and production/native unknowns are explicit in EVIDENCE.md. Request authorizes planning and implementation; master plan defines development verification, no invented approval gate.
