# دليل استخدام سجلات الأخطاء / Error Logs

تم إعداد هذا الدليل بعد قرار Phase 06: Verified للنطاق التطويري والفحوص الآلية المعتمد يوم 2026-10-17. اختبار الهاتف الفعلي مؤجل بطلب المستخدم تحت `PROD-026`.

## الوصول للسجلات

مسؤول الشركة يمنح صلاحيات مستقلة لعرض القائمة والتفاصيل والتصدير. من قسم **Administration / الإدارة** افتح **سجلات الأخطاء**. تعرض الشاشة أخطاء الشركة الحالية فقط؛ تبديل الشركة يغيّر نطاق النتائج. ظهور القائمة لا يمنح تلقائيًا صلاحية التفاصيل أو التصدير.

الـ Super Admin يفتح **سجلات أخطاء النظام** من قسم **Administration / الإدارة**، ويمكنه مراجعة السجلات العامة وأخطاء الشركات وفق صلاحياته. من قائمة **Settings / الإعدادات** افتح **إعدادات سجلات الأخطاء**. تظل صلاحية الإعدادات مستقلة ولا تشترط امتلاك صلاحية عرض سجل النظام. على الموبايل ستجدها داخل شاشة Settings الموجودة، في قسم إعدادات النظام، عند امتلاك الصلاحية.

| الوظيفة | Web | Mobile |
| --- | --- | --- |
| سجل الشركة | `/advanced-tools/error-logs` | `/advanced-tools/error-logs` |
| سجل النظام | `/super-admin/error-logs` | `/system-error-logs` |
| مدة الاحتفاظ | `/super-admin/error-log-settings` | `/error-log-settings` |

## البحث والتفاصيل والتصدير

1. في الويب اضغط أيقونة **تصفية** في رأس الصفحة لفتح شريط البحث والمعايير المشترك. اختر الفترة من منتقي التاريخ والمستخدم والمصدر وحالة HTTP، واستخدم **إعادة تعيين** لمسح المعايير. إغلاق الشريط أو التبديل بين الجدول والبطاقات يحتفظ باختياراتك. على الموبايل استخدم البحث وزر الفلاتر الموجودين في القائمة. فلاتر الأيام تستخدم حدود اليوم بتوقيت UTC؛ وقت عرض السجل يتبع اللغة والتنسيق المحلي.
2. بدّل بين الجدول والبطاقات. العدد والترقيم يعكسان نتيجة البحث على الخادم.
3. افتح تفاصيل السجل عند امتلاك الصلاحية. معرف الربط يساعد الدعم على تتبع الطلب. بيانات الشركة لا تعرض عنوان IP أو إطارات الدوال؛ التفاصيل الفنية الآمنة متاحة في شاشة النظام فقط.
4. من أيقونة التصدير في رأس صفحة الويب اختر **تصدير XLSX** لتصدير نتائج الفلاتر، بحد أقصى 5,000 سجل. لو زادت النتائج، ضيّق الفترة أو الفلاتر ثم أعد المحاولة. على الهاتف تُفتح مشاركة الملف، ثم يُحذف الملف المؤقت من ذاكرة التطبيق.

## تغيير مدة الاحتفاظ

القيمة الافتراضية **90 يومًا**. يدخل الـ Super Admin إلى إعدادات السجل، ويختار تعديل، ثم يكتب عددًا صحيحًا من **1 إلى 3650** ويحفظ. الصلاحية المطلوبة للتعديل مستقلة عن العرض.

لو تغيّرت الإعدادات عند مسؤول آخر، تظهر رسالة تعارض وتظل القيمة المكتوبة موجودة. اختر إعادة تحميل المراجعة، راجع المسودة، ثم احفظ. الإغلاق أثناء وجود تعديلات يعرض تأكيد تجاهل التغييرات.

التنظيف التلقائي يعمل عند بدء العامل ثم كل ساعة بدفعات محدودة، ويحذف السجلات الأقدم من المدة المحددة. تقليل المدة يجعل السجلات القديمة مؤهلة للحذف في دورة التنظيف التالية؛ السجلات ليست شاشة بيانات قابلة للتعديل أو الحذف اليدوي. عدادات الطابور والسجلات المهملة والكتابات الفاشلة تساعد الـ Super Admin على ملاحظة تعطل التسجيل.

## ما يتم تسجيله

المصادر المدعومة: أخطاء API، ومحاولات مهام الخلفية الفاشلة، وأخطاء الويب والموبايل القابلة للالتقاط أثناء الجلسة المعتمدة. تشمل HTTP حالات التحقق والأعمال و401/403/404 والحالات الأعلى؛ الطلب الملغى دون خطأ وطلبات الصحة والسجل نفسه مستثناة لتقليل الضوضاء ومنع التكرار.

لا تُرسل رسائل الاستثناء الخام أو كلمات المرور أو الطلبات أو الروابط الخاصة من العميل. التسجيل محدود وغير متزامن: تعطل الشبكة أو قاعدة البيانات أو انتهاء العملية قبل الحفظ قد يمنع وصول بعض السجلات (`RISK-010`). أعطال نظام الهاتف الأصلية قبل تشغيل JavaScript ليست ضمانًا يوفره هذا السجل. المشاهدة والتعديل والتصدير تتطلب اتصالًا وصلاحية مباشرة من الخادم.

## عرض التفاصيل ونسخها — تحديث 19 أكتوبر 2026

افتح تفاصيل السجل من إجراء العرض. تظهر رسالة السجل أولًا، ثم بيانات العملية والمستخدم، وللـ Super Admin تفاصيل التشخيص الفني. النص الطويل يلتف داخل النافذة، وزر «نسخ رسالة الخطأ» ثابت في أسفلها وينسخ التقرير المسموح بالكامل، بما فيه الوقت المحلي وUTC ومعرف التتبع. ظهور نجاح النسخ يؤكد الإتمام؛ لو المتصفح رفض الوصول للحافظة تظهر رسالة فشل ويمكن الضغط على الزر للمحاولة مرة أخرى.

السجلات الجديدة من الخادم تضيف نوع الاستثناء والأخطاء الداخلية وأكواد قاعدة البيانات ومسار التنفيذ وبيانات الطلب أو مهمة الخلفية. لا تشمل كلمات المرور أو التوكنات أو محتوى الطلب أو نص SQL أو رسالة الاستثناء الخام؛ أكواد SQL المعروفة لها تصنيفات سبب ثابتة. تفاصيل التشخيص وعنوان IP تظل للـ Super Admin؛ سجل الشركة ونسخه يحترمان نفس حدود العرض. التفاصيل القديمة لا يمكن استعادتها لو لم تُسجّل وقت الخطأ. يصل حد النص التشخيصي المحفوظ إلى 32768 حرف JSON، وعند بلوغ الحدود تظهر علامة DiagnosticsTruncated. أرقام أسطر الكود تظهر فقط إذا كانت رموز التصحيح متاحة.

الموبايل يحتفظ بعرضه الحالي للنص الفني المسموح القابل للتحديد؛ زر النسخ الجديد يخص الويب. اختبار الهاتف الفعلي ما زال PROD-026 وفق التأجيل المتفق عليه.


### حالة قسم تشخيص الخطأ على الويب

في عرض الـ Super Admin يظهر قسم «تشخيص الخطأ / Error diagnostics» بعد تحميل التفاصيل، حتى لو لم تُحفظ بيانات فنية لهذا السجل. تظهر وقتها رسالة «لم تُسجّل تفاصيل تشخيص فنية لهذا السجل»، ويشملها التقرير المنسوخ. عدم وجود بيانات قد يخص سجلًا قديمًا أو بلاغ عميل أو خطأ دون استثناء. عرض الشركة لا يتضمن هذا القسم حسب فصل الصلاحيات المعتمد.
