# نصوص واجهة النظام — دليل مدير النظام

افتح **Administration → Settings → System UI texts**، أو **الإدارة → الإعدادات → نصوص واجهة النظام**. يظهر التبويب لحساب مدير النظام الذي يملك SystemUiTexts:View. يحتاج الحفظ إلى SystemUiTexts:Edit والاسترجاع إلى SystemUiTexts:Reset. في كل الحالات يجب أن تكون شاشة النص نفسها مسموحة للمستخدم؛ يطبق الخادم هذا القيد على البحث والحفظ والاسترجاع وحزمة التشغيل.

اختر مصدر الواجهة (Web أو Mobile)، ثم اللغة الأساسية للمقارنة واللغة المستهدفة، وابحث بالمفتاح أو النص. يعرض الجدول النص الأساسي والحالي وحالة التخصيص، مع فلاتر الكل/غير المخصص/المخصص وأدوات الجدول المعتادة. يدعم الموبايل Table وCards بنفس مصدر البيانات والفورم المشترك.

للتجربة على الويب: اختر Web interface · platform-auth وابحث عن **systemUiTexts.title**. اختر لغة الواجهة الحالية كلغة مستهدفة، وغيّر العنوان مثلًا إلى «نصوص إدارة النظام»، ثم احفظ. يتغير عنوان شاشة النصوص بعد وصول الحزمة المحدثة. استخدم Reset text لاستعادة النص الأصلي. عنوان تبويب التنقل نفسه له مفتاح منفصل menu.systemUiTexts في Web interface · core. للموبايل اختر Mobile app · translation؛ يتوفر systemUiTexts.title وعنوان التنقل navigation.systemUiTexts.

تُحفظ التخصيصات في إعدادات النظام وتطبق على جلسات مدير النظام المصرح لها بالشاشة. تحتفظ الشركات بتخصيصاتها المنفصلة. تظل العربية والإنجليزية هما اللغتين المتاحتين، ويظل اختيار المستخدم للغة ساريًا. لا توجد هوية شركة افتراضية أو حقل لتعديل اللغة الافتراضية العامة في هذا التبويب.

احتفظ بمتغيرات النص كما هي، مثل {{name}} أو {0} أو <0>…</0>. تظهر أخطاء الإدخال أسفل الحقل. إذا عدّل مسؤول آخر النصوص أولًا، يعرض الحفظ تعارضًا؛ احتفظ بالمسودة أو أعد تحميل القيم الحالية ثم طبّق تعديلك. إلغاء تعديل غير محفوظ يستخدم تنبيه التغييرات المشترك. الاسترجاع يحذف تخصيص النص المحدد ويعيد النص المشحون مع التطبيق.

تحدّث الشاشة الحالية بياناتها وحزمة الترجمة بعد الحفظ. تلتقط الجلسات الأخرى التغيير عند إعادة التحميل، أو التحديث الدوري (نحو دقيقة أثناء نشاط التطبيق)، أو إعادة الاتصال. تُزال تخصيصات الجلسة السابقة عند تبديل الهوية/الشركة أو فقد صلاحية الجزء. يلزم اتصال فعلي للتعديل؛ لا يعيد الموبايل إرسال تعديلات ترجمة محفوظة في طابور دون اتصال.

انشر دليل النصوص المتطابق مع API والويب والموبايل معًا؛ اختلاف نسخة الدليل يرفضه الخادم بدل تطبيق مفاتيح غير متوافقة. Migration **20261019150523_AddSystemUiLocalization** مطبقة على قاعدة التطوير. ليس مطلوبًا إنشاء Migration إضافية لهذا التغيير.
