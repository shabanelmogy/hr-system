# Guides

Rules that apply to every module. Feature-specific books live with their
module under [`../modules/`](../modules/README.md).

| Folder | Covers |
| --- | --- |
| [`shared/`](shared/README.md) | Ownership, reuse, screen patterns, permissions, cross-platform conventions |
| [`api/`](api/README.md) | Backend architecture, feature workflow, ADRs, migrations, configuration, deployment |
| [`web/`](web/README.md) | Next.js architecture, generator, performance, release gates |
| [`mobile/`](mobile/README.md) | Expo architecture, style, capability and release rules |
